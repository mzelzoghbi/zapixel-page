Empire State in Blue Light wallpaper

Empire State in Blue Light is a free architecture wallpaper from the ZaPixel catalogue, sized for iPhone and Android lock and home screens.

Free, with no account. The full 4K file is in the app.

Set it on iPhone

  1. Open Empire State in Blue Light in ZaPixel and preview it on the lock screen.

Set it on Android

  1. Open Empire State in Blue Light in ZaPixel.
