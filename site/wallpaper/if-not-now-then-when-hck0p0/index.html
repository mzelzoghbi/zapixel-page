If Not Now, Then When? wallpaper

If Not Now, Then When? is a free dark and calligraphy wallpaper from the ZaPixel catalogue, sized for iPhone and Android lock and home screens.

Free, with no account. The full 4K file is in the app.

Set it on iPhone

  1. Open If Not Now, Then When? in ZaPixel and preview it on the lock screen.
  2. Tap Save — it goes straight to Photos.
  3. In Photos, tap Share › Use as Wallpaper.

Set it on Android

  1. Open If Not Now, Then When? in ZaPixel.
  2. Tap Set, then choose home screen, lock screen or both. Undo is one tap away.
